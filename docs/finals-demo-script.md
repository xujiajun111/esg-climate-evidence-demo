# 决赛 5 分钟 Demo 演示脚本

版本：v1.0  
建议总时长：4 分 45 秒  
备用方案：本地静态构建 + 录屏

## 1. 演示前检查

- 使用 Chrome 最新稳定版；
- 打开本地静态构建或公网页面；
- 关闭无关标签页和通知；
- 点击“5 分钟评审演示”确认内置样例可以加载；
- 准备离线构建包、5 分钟录屏和关键页面截图；
- 明确现场展示是“实际运行”还是“预置结果”。

## 2. 演示节奏

### 0:00-0:25 业务问题与决策目标

讲解：

- 可持续报告披露长、指标分散、承诺与行动不一定对应；
- 分析人员真正面对的是有限复核时间；
- Demo 目标是在时间预算内优先复核高价值证据链。

页面重点：结果总览、复核时间约束、浏览器本地处理。

### 0:25-1:20 从文本到证据链

操作：

- 展示内置报告实际完成文本抽取；
- 查看证据链图谱；
- 切换完整、C、A、P 类型；
- 指出一条完整链路和一条断点链路。

讲解：

- 承诺、行动、绩效逐条保留原文和页码；
- 断点只是待核线索，不直接给企业定性。

### 1:20-2:00 原文追溯与人工复核

操作：

- 点击“查看原文”；
- 展示 PDF 页面和原句高亮；
- 将一条任务标记为确认或存疑。

讲解：

- 人工可以改结论，模型不能自动定性；
- 扫描页、图表和复杂版式仍需人工核对。

### 2:00-3:05 运筹模型与优化结果

操作：

- 将复核预算从 90 分钟调到 60 分钟；
- 切换稳健、期望、进取模式；
- 展示建议复核队列变化；
- 指出优化方案与基准方案的风险覆盖差异。

讲解：

- 决策变量是任务是否进入复核队列；
- 目标是有限时间内最大化风险覆盖；
- 约束是人工时间预算；
- 0/1 背包精确求解；
- 低置信度优先不一定等于最有业务价值。

### 3:05-3:45 验证与鲁棒性

操作：

- 展示预算敏感性曲线；
- 展示 25 次价值扰动的选择重合度；
- 切换到“结果可信度与方法边界”。

讲解：

- 14/14 是防退化回归，不是总体准确率；
- 当前未完成双人金标准，因此不宣称生产级 F1；
- 已明确 OCR、表格和跨年度归并的边界。

### 3:45-4:20 AI 应用与风险控制

操作：

- 打开“AI 工具使用说明”；
- 说明当前公网默认规则模式；
- 如现场配置模型，展示 AI 建议与人工复核分离。

讲解：

- AI 只接收候选和必要原文片段；
- 失败自动回退规则；
- 原文、页码、分析模式和复核记录保留。

### 4:20-4:45 审计导出与落地

操作：

- 打开导出弹窗；
- 简述 JSON 和 CSV 内容。

讲解：

- 可接入 ESG 底稿、报告审阅或企业知识库；
- 默认浏览器本地处理，可扩展私有化模型和企业系统接口。

## 3. 评审问答准备

### 为什么不是普通信息抽取？

因为系统将披露文本转换为可分配、可复核、可追踪的证据任务，并进一步解决有限
复核时间下的审查组合优化。

### 为什么使用 0/1 背包？

任务可以选中或不选中，人工时间为整数分钟，目标是受预算约束的风险价值最大化，
与背包问题结构一致。问题规模较小，浏览器端可以精确求解。

### 优化结果与真实风险的关系？

优化结果是复核资源分配建议，不是企业风险概率或违规认定。任务价值是可解释的
代理指标，需要通过专家标定和历史复核结果持续校准。

### 如何证明 AI 有用？

目前只能证明流程可运行、规则回归稳定和真实报告可以抽取。AI 增益仍需通过人工
金标准对比规则、规则+AI 和人工分析三组结果后量化，不能使用模型自报置信度替代。
