# 分析准确性与优化报告

版本：规则分析器 v0.2  
更新日期：2026-11-16

## 1. 当前结论

当前规则分析器在团队提供的标注口径和 9 个回归案例上全部通过。结果只代表这些已定义案例，不等同于对全部上市公司报告的生产级准确率。

可确认的部分：

- 承诺、行动、绩效三类要素能在演示样本中正确分类；
- A/B/C 三类断点的代表性案例均能正确生成；
- 口号不会直接触发三类要素；
- 未来计划不会被误判为已实施行动；
- 集团汇总绩效不会被当作行动级绩效；
- 年份不会被取作绩效数值；
- 同一句出现多个要素信号时坚持“一句话一个标签”，并标记待人工复核。

尚不能确认的部分：

- 没有足够真实报告样本，不能声称 100% 召回；
- PDF 表格、图表、扫描页可能丢失信息；
- 跨多年报告的同一承诺归并仍依赖人工确认；
- 当前为规则分析，不是大模型语义理解。

## 2. 回归范围

测试文件：`tests/analyzer-regression.mjs`

| 案例 | 验证重点 |
| --- | --- |
| 钢铁企业 | 完整链路、汇总绩效不能替代行动级绩效、B 类断点 |
| 化工企业 | 有承诺无跟进、A 类断点 |
| 电力企业 | 有绩效无行动、C 类断点 |
| 电子科技 | 口号不得误识别 |
| 制造企业 | 碳台账、碳管理培训、高耗能设备 |
| 材料企业 | 未来计划不得视为行动 |
| 玻璃企业 | 无承诺时行动与单项绩效直接关联 |
| 水泥企业 | 同句多要素按一个标签处理 |
| 电力企业 | 年份不得误作绩效数值 |

## 3. 本轮已优化

### 3.1 扩大气候词库

新增碳台账、碳盘查、碳核查、碳足迹、碳交易、耗能、能源消耗、能源消费、余压、绿证等表达，减少“明明有行动但未被扫描”的漏识别。

### 3.2 修正句子切分

只在句号、问号、感叹号处切句，不再把中文分号强行切成两句话，符合“一句话只分配一个标签”的标注规则。

### 3.3 修正数值提取

绩效值必须匹配数值和单位，不再把句首年份 `2024年` 当作绩效数值。支持 `%`、百分点、万吨、吨标煤、MWh、GJ 等单位。

### 3.4 加强行动与绩效关联

- 对“余热发电量”等带有明确技术对象的结果，允许直接关联余热改造行动；
- 没有承诺时，也能独立关联行动和对应绩效；
- 只有集团汇总量、无法指明具体行动时，仍保留 B 类断点。

### 3.5 增加无承诺行动断点

即使报告未提供对应承诺，只要识别到独立行动但没有行动级量化结果，也会生成 B 类候选，避免这类信息断点被漏掉。

## 4. 推荐继续优化

按对准确率的影响排序：

1. **建立真实报告金标准集**：至少覆盖 30 到 50 份报告、每类要素 100 条以上，并由两名成员独立标注和复核。
2. **引入大模型做语义分类，规则负责校验**：模型处理复杂表述，规则负责年份、数字、未来计划和断点一致性检查。
3. **按章节切分上下文**：识别“气候目标、减排项目、环境绩效”等章节，避免跨章节错误关联。
4. **增加表格解析和 OCR**：真实 ESG 报告中的绩效大量位于表格和图表，仅抽取正文会漏识别。
5. **建立跨年度承诺台账**：同一承诺沿用固定编号，逐年追加行动和绩效，才能正式判断 A 类断点。
6. **增加人工纠错回流**：前端允许复核人员改标签和关联关系，修正结果作为下一轮 Prompt 与回归集。

## 5. 建议验收指标

正式比赛或对外演示前，建议以人工金标准计算：

- 三类要素分类 Macro-F1 不低于 90%；
- 每条要素原文可追溯率 100%；
- 页码正确率不低于 98%；
- A/B/C 断点分别统计精确率和召回率；
- 所有断点保持“待人工复核”，不得直接输出企业负面结论。

当前回归测试是防退化基线，不代替真实金标准评测。
