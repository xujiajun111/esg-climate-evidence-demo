# 有限复核时间下的证据任务优化模型

版本：v1.0  
更新日期：2026-11-25

## 1. 业务问题

ESG 分析人员从报告中识别出承诺、行动、绩效和断点候选后，仍需投入人工时间
核验原文、分类和关联关系。实际工作中复核时间有限，因此需要决定：

> 在给定人工复核预算下，哪些证据任务应优先进入本轮审查队列？

## 2. 数学模型

### 2.1 决策变量

对每个候选任务 i：

```text
x_i = 1，任务 i 进入本轮复核队列
x_i = 0，任务 i 不进入本轮复核队列
```

### 2.2 目标函数

```text
max sum(v_i * x_i)
```

其中：

- `v_i` 是任务风险价值；
- 基础价值由断点类型或要素类型、目标时限紧迫度、人工未决状态和缺失证据数量计算；
- 稳健模式使用价值下界，期望模式使用期望值，进取模式使用价值上界。

### 2.3 约束

```text
sum(t_i * x_i) <= B
x_i in {0, 1}
```

其中：

- `t_i` 是任务预计人工复核分钟数；
- `B` 是本轮可投入的复核预算。

## 3. 求解方法

任务规模在浏览器端可控，因此使用整数分钟预算的 0/1 背包动态规划精确求解。
算法输出：

- 建议复核任务；
- 使用分钟数；
- 风险覆盖比例；
- 高风险任务覆盖比例；
- 目标函数值。

## 4. 基准方案

| 基准 | 规则 |
| --- | --- |
| 文档顺序 | 按证据在页面中出现的顺序依次复核 |
| 低置信度优先 | 优先复核规则或模型匹配度最低的任务 |
| 风险价值贪心 | 按单位人工时间风险价值从高到低选择 |
| 优化组合 | 0/1 背包精确求解 |

同一预算下比较风险覆盖和任务构成，避免只汇报优化方案的绝对指标。

## 5. 敏感性分析

页面展示 30、60、90、120 和 180 分钟预算下的：

- 优化方案风险覆盖；
- 低置信度基线的风险覆盖；
- 建议复核任务数量。

预算增加时，覆盖曲线应单调不减。边际收益下降说明继续增加人工时间可能不再是
最高效的资源使用方式。

## 6. 鲁棒性分析

对每个任务价值施加 80%-120% 的确定性随机扰动，重复求解 25 次，统计：

- 与基准优化队列的平均 Jaccard 重合度；
- 扰动情景下的最差风险覆盖率。

该分析只说明模型在当前风险估值范围内的选择稳定性，不等同于真实企业风险准确率。

## 7. 假设与边界

- 任务价值是可解释的代理指标，不是企业实际违规概率；
- 人工复核分钟数为估计值，可根据团队实测标定；
- 任务之间暂按独立处理，未建模同一人员跨任务学习效应；
- 断点和要素只允许进入一次复核队列，避免重复计算；
- 复核结论仍由人工确认。
